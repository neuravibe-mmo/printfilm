# Git Operations Rules

## Strict Policy on Git Commit and Git Push
- **NEVER** automatically run `git push` or `git commit`.
- Do NOT stage, commit, or push code unless the user explicitly and directly requests it (e.g. explicitly typing "git push", "push code", "commit", etc.).
- All code edits, fixes, and builds must remain strictly in the local working copy.
- The user will inspect changes locally and handle commits/pushes themselves, unless explicitly instructed otherwise in the prompt.
